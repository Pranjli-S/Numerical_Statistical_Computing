## Project Overview
This repository contains C++ implementations of numerical methods, organized as follows:

1. **Bisection Method**
2. **Regula Falsi Method**
3. **Newton-Raphson Method**
4. **Gauss Elimination Method**
5. **Jacobi Iteration Method**
6. **Gauss-Seidel Method**
7. **Newton Forward Interpolation**
8. **Newton Backward Interpolation**

## How to Use
* Each method is contained in its own `.cpp` file.
* Compile using `g++` and follow the terminal prompts for input.
